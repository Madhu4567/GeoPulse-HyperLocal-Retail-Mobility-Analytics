# Project Scope

## Problem
Retail location planning can benefit from time-aware footfall patterns rather than static indicators alone.

## Prototype objective
Use synthetic GPS-like pings and synthetic store catchment polygons to demonstrate hourly footfall, spatial assignment, catchment overlap, and an estimated traffic-overlap metric.

## Initial exclusions
- Real consumer location data
- Production retail recommendations
- Claims about actual customer behaviour
- Live integrations not yet configured
